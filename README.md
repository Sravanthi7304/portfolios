# Sravanthi.dev – Web Developer Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript. It showcases my education, internships, skills and projects in a single, lightweight page.

**Live preview:* https://portfolios-ux.vercel.app/

## Features

- Clean, single-page layout with a sticky navigation bar
- Hero section with a short introduction and call-to-action buttons
- Education and experience shown as timelines
- Skills and project cards, including work in progress
- Light and dark theme, following your system setting with a manual toggle
- A few subtle animations: page-load fade-in, scroll reveal, hover effects and active nav highlighting
- Fully responsive for mobile, tablet and desktop
- Respects the "reduce motion" accessibility setting

## Built with

- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript (IntersectionObserver, localStorage for the theme)
- Google Fonts: Bricolage Grotesque and Hanken Grotesk
